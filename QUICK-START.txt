FASTEST PATH
============
1. Upload this folder to a GitHub repo.
2. Cloudflare -> Workers & Pages -> Create -> Pages -> Import repo.
3. Build command: BLANK
4. Output directory: public
5. Deploy.
6. Create a KV namespace.
7. Pages project -> Settings -> Bindings -> Add KV:
      Variable name: WEDDING_CONFIG
8. Pages project -> Settings -> Variables and Secrets -> Add:
      Name: ADMIN_PASSWORD
      Set a private passcode and choose Encrypt
9. Redeploy.
10. Open https://YOUR-SITE.pages.dev/setup/
11. Unlock with the ADMIN_PASSWORD you created.
12. Add both people's Venmo / Cash App / Zelle / Apple Cash info and save.
13. Open https://YOUR-SITE.pages.dev/card/
14. Print at ACTUAL SIZE / 100% on 4x5 cardstock.

The printed QR points only to the permanent site URL, so you can change payment details later without reprinting it.
